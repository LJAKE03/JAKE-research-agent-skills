# 统一科研流程示例

以下示例都使用同一流程。模型和功能 Skill 由总控自动选择，用户不选择模式。

## 示例 1：泛化科研项目

用户：

> 帮我做船用氢燃料供给系统电动阀故障预测研究。

1. 战略总控 判断目标、数据和交付物存在高影响歧义，调用 `01` 形成任务合同。
2. 战略总控 按可用调用形态（角色 `agent_type`、显式模型 spawn，或一次性只读 `codex exec`）以 `fork_turns=none` 创建 证据 Worker 子线程并发送有界检索任务卡；证据 Worker 返回传感器、数据集、评价方法和来源定位。
3. 战略总控 综合证据并锁定研究问题、方法候选和真实依赖。
4. 只有数据、模型、验证和交付之间的依赖需要持久化时才调用 `03`。
5. 关键路线和参数交用户确认，最终由 战略总控 验收。

## 示例 2：SCI 小论文

用户：

> 根据现有仿真结果写一篇 SCI 小论文。

1. 战略总控 检查研究问题、数据、图表、方法和目标期刊。
2. 需要补充文献时，证据 Worker 返回证据表和定位。
3. 战略总控 锁定论文论点图、提纲、数据解释和引用编号。
4. 战略总控 按可用调用形态（角色 `agent_type`、显式模型 spawn，或一次性只读 `codex exec`）以 `fork_turns=none` 创建 输出 Worker 子线程；输出 Worker 按章节写作包生成草稿，不新增事实或引用。
5. 战略总控 只对方法、关键数据解释和最终科学结论做紧凑验收，不重写全文。

## 示例 3：文献综述

用户：

> 做一篇预测性维护综述。

1. 战略总控 明确综述用途、对象、时间范围和交付物。
2. 证据 Worker 执行检索、筛选、元数据提取和证据矩阵整理。
3. 战略总控 评估来源、综合主题、分歧和缺口。
4. 战略总控 锁定综述结构与论点后，输出 Worker 生成正式文本。
5. 证据 Worker 核对引用覆盖，战略总控 验收最终综合结论。

## 示例 4：已锁定内容的写作

用户：

> 提纲、论点和引用都确认了，请写成英文 Results。

1. 战略总控 检查写作包是否完整。
2. 输出 Worker 根据锁定提纲、数据、引用编号和语言要求生成草稿。
3. 战略总控 只检查是否忠实、是否越界和关键结论是否准确。
4. 不重新检索，不重建项目计划。

## 示例 5：一次官网核验

用户：

> 查某科研软件官网当前稳定版本，只给版本号、发布日期和官方链接。

1. 战略总控 按可用调用形态（角色 `agent_type`、显式模型 spawn，或一次性只读 `codex exec`）以 `fork_turns=none` 创建 证据 Worker 子线程并发送一个有界任务卡。
2. 证据 Worker 返回三个字段和官方定位。
3. 战略总控 检查来源后直接答复，不创建阶段或项目状态。

## 示例 6：关键仿真诊断

用户：

> Fluent 开启能量方程后发散，给出下一轮最小诊断。

1. 战略总控 区分已知事实与候选根因。
2. 当前只激活一个单变量试验，定义观测量和停止条件。
3. 其他假设保留为后续候选，不同时修改多个变量。
4. 该方法判断不委派给 证据 Worker 或 输出 Worker。

## 示例 7：内容已锁定的考公选调 PDF

用户：

> 岗位、待遇、来源和字段都已经核对完，请整理成一份 PDF。

1. 战略总控 确认筛选结论、字段顺序、来源编号、标题层级和验收条件都已锁定。
2. 输出 Worker 组织 PDF 所需的标题、表格和说明文字，不新增待遇数据，也不改变岗位判断。
3. 专用 PDF 工具负责实际落盘、渲染和版面检查。

## 示例 8：不能因文件后缀提前路由

用户：

> 从几份招录 PDF 中判断我能报哪些岗位，再做 Excel 优先级表。

1. 证据 Worker 提取 PDF 事实和来源定位。
2. 战略总控 决定资格规则、分类和优先级。
3. 决策锁定前不调用 输出 Worker；锁定后如只剩单表内容与格式组织，才由 输出 Worker 生成输出规格，并由表格工具写入和验证。
