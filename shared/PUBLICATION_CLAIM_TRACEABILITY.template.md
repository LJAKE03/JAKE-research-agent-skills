## 5. 审稿与编辑风险登记

优先复用已有 L1/L2 质量门发现，不为填表重复启动审稿，也不新增常驻 Reviewer Agent。

| 类别 | 潜在异议 | 依据定位 | 严重度 | 对声明的影响 | 处置与验证 | 状态 |
|---|---|---|---|---|---|---|
| 创新性 / 重要性 / 方法 / 证据 / 表达 / 期刊匹配 |  |  | CRITICAL / MAJOR / MINOR |  |  | OPEN |

- CRITICAL：会使核心命题、方法或科学有效性失效。
- MAJOR：会显著削弱贡献、证据充分性或可投稿性。
- MINOR：不改变科学结论，可在局部修订中关闭。
- 投稿前不得存在未关闭的 CRITICAL / MAJOR 异议。

状态：OPEN / RESOLVED / ACCEPTED_WITH_RATIONALE。CRITICAL 和 MAJOR 不得仅以语言润色或“用户接受风险”替代科学修复。
