# Proactive inquiry and memory evolution

- 状态：implemented in v2.4.0 candidate
- 范围：共享协议、总控、需求澄清、项目模板、个人工作区、测试与文档

## 问题

现有经验闭环能阻止未经批准的全局写入，但没有统一规定如何主动寻找关键信息、如何按重要性控制总结精度，以及如何在项目收尾主动发起可选择的记忆授权。

## 验收标准

- 公开事实先调研，不转问用户；
- 只问高影响且用户独有的信息，问题说明原因与取舍；
- A/B 详细、C/D 简要或仅项目保留；
- 收尾先给候选摘要，再询问全部/部分/拒绝/延后；
- 未回复不写入，重复出现不自动晋升；
- 当前明确指令优先于历史记忆；
- 确定性测试和行为评测覆盖上述边界。
